# sudebni_arest — два документа по эталонам

**Версия 1.1.0.** Сотрудник передает судебный акт/исполнительный лист или сведения клиента; LLM заполняет две исходные формы Word. Начальная инструкция: [SKILL.md](SKILL.md).

```text
Примени https://github.com/javejoker/sudebni_arest/blob/main/SKILL.md
По приложенному акту и данным клиента заполни оба исходных Word-шаблона.
Без уточняющих вопросов выдай два DOCX. Дату решения не путай с датой
вступления в силу. Поля даты и способа уведомления оставь ручными,
с прочерками, курсивом и подчеркиванием. Недостающие сведения не выдумывай.
```

## Что изменилось в V1.1

`decision_date` и `legal_force_date` разделены. Дата вступления в силу хранится в локальном отчете и не занимает место даты решения. Дата из контекста «рассмотрев гражданское дело» проверяется отдельно от даты выдачи листа. Числовые даты по явным меткам проверяет консервативный помощник; он не заменяет чтение PDF моделью.

Два фрагмента уведомления всегда оставляются для ручного заполнения, даже при переданной дате. Настоящие свойства Word `italic` и `underline` сохраняются и проверяются; подчеркивание не является календарным виджетом. Номер дела сохраняет суффиксы, без повторного знака `№`. БИН истца заполняется под меткой БИН, ИИН — под меткой ИИН.

Оба оригинала DOCX неизменны. Юридические абзацы не переписываются; правовая экспертиза V1.1 не проводилась. Длинные данные могут изменить переносы строк/страниц, в том числе из-за 93 пробелов перед «Ответчик» в оригинале ходатайства.

## Совместимость

Один и тот же [контракт](docs/PORTABILITY.md) предназначен для ChatGPT, Gemini, DeepSeek и Claude. Для результата именно в двух исходных DOCX среда должна читать полные файлы, запускать Python 3.10+ и прикладывать готовые файлы. Текстовая LLM без исполнителя не может выполнить этот контракт одной ссылкой. Проверены код и повторяемость на одинаковых данных; живые чаты четырех провайдеров не тестировались.

## Для сопровождающего

```bash
python -m unittest discover -s tests -v
python scripts/fill_documents.py --data tests/synthetic_case.json --out new_synthetic_output
```

Зависимостей pip и ключей API нет. Пользовательские PDF и JSON в репозиторий не помещать. [Отчет V1.1](docs/QA_V11.md); отчеты без V11 относятся к исторической V1.
