# Сопровождение V1.1

Рабочая инструкция сотрудников — SKILL.md; этот файл предназначен только сопровождающему.

Перед изменением прочитать текущий commit, оба шаблона, field_map.json, case_schema.json и scripts/fill_documents.py. Не заменять эталоны новыми документами. Не изменять юридический текст без отдельного поручения владельца. Оставлять locked-поля уведомления ручными, даже если awareness_date передана.

Изменения проверять `python -m unittest discover -s tests -v`, запуском CLI на синтетических данных и просмотром всех страниц обоих результатов после рендеринга. Обновлять manifest.json, не включать его собственный хеш в себя. Клиентские данные, результаты, логи, скриншоты не публиковать. Не сокращать ФИО и не удалять исходные пробелы для совпадения страниц.

Разделять технические тесты кода, визуальную проверку и живое испытание в чате каждого провайдера. Не объявлять совместимость всех чатов по симуляции названий провайдеров.

Для обычных правок по утвержденным правилам: Terra — Medium. Для анализа новой неоднозначной маршрутизации: Sol — High.
